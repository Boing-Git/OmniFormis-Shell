# Dependencies

This project requires the following packages to be installed:

## Arch Linux

```bash
sudo pacman -S base-devel git fish bash curl unzip xdg-utils
```

## NixOS

The NixOS configuration includes all necessary dependencies.

## Manual Installation

For other distributions, install the following packages manually:
- `base-devel`
- `git`
- `fish`
- `bash`
- `curl`
- `unzip`
- `xdg-utils`
