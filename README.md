# OmniFormis Shell

A Hyprland + Quickshell desktop configuration for Arch Linux and NixOS.

## Installation

Clone the repository:

```bash
git clone https://github.com/Boing-git/OmniFormis-Shell.git
```

Then run the installer:

```bash
cd OmniFormis-Shell && ./install.sh
```
